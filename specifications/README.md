# Formal specifications

`protocol/` describes component behavior. This directory defines the **formal interfaces and contracts** consumed or produced by those components.

Planned areas:

- `data_contract/` — logical-field and tariff-code requirements;
- `configuration/` — experiment/configuration schemas;
- `inputs_outputs/` — machine-readable schemas for rankings, evidence, explanations and metrics;
- `manifests/` — replication and reference-run manifest schemas.

A protocol sheet should link to the relevant specification files. Specifications must not contain private implementation code.
