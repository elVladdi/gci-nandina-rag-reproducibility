# Reproducibility data

This directory is reserved for data artifacts that are both necessary for reproduction and legally/ethically appropriate to redistribute.

Before adding an artifact, document it in `docs/DATA_PROVENANCE.md` and define:

- source;
- transformation path;
- version;
- SHA-256;
- schema/cardinality;
- redistribution status.

Restricted inputs must not be committed. When redistribution is not permitted, provide reconstruction/placement instructions and expected hashes instead.
