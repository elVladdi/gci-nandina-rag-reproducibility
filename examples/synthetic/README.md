# Synthetic replication example

A future stable publication should include a small redistributable dataset and matching configuration designed to exercise the published protocol without exposing administrative data.

The example should cover, at minimum:

- unique analysis identifiers;
- grouped observations so group-safe splitting can be tested;
- multiple tariff hierarchy levels;
- historical support and unsupported/edge cases where useful;
- a small normative corpus with declared hierarchy coverage;
- expected manifests and selected test-vector outputs.

Synthetic data must be clearly marked as demonstrative and must not be presented as evidence from the reference experiment.
